# AI 工作日志

本目录保存与本仓库协作的 AI 代理（Claude Code）的操作日志，**纳入 git 跟踪并 push**，
确保跨平台 / 跨机器可见（新机器上 `git pull` 即可获得完整记录）。

## 文件
- `CLAUDE_LOG.md` — Claude Code 的操作日志

## 日志规约
1. **每次执行实质操作后都要追加日志**：新建 / 修改 / 删除文件、跑训练、调参、
   git 操作、关键诊断结论等。**删除 / 回退与新增同等重要，必须记录**（删了什么、
   是不是故意的、为什么删 —— 三要素都要写，避免后续会话误判为意外丢失）。
2. **不记录用户的提问 / 闲聊** —— 只记录 AI 实际做了什么、为什么、结果如何。
3. 每条目标注日期；保持时间顺序一致。
4. 详细的设计 / 实验记录可单独成文（放 `TODO_list/` 或根目录），日志里留指针即可。
5. 本目录必须保持 git 跟踪并可 push。
6. **每次修改根目录 `CLAUDE.md`（项目说明）都要在 `CLAUDE_LOG.md` 追加一条记录。**

> 注：`CLAUDE.md` 是仓库根目录的"项目说明书"（怎么干活的参考知识），
> 与本目录的"工作流水账"作用不同，请勿混淆。
